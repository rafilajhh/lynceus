# Truck-bed demo photos

Close-up photos of a refuse-truck bed, generated for the demo (image model,
2026-10-15). Three gate scenarios:

| File | Scenario | Contents |
|---|---|---|
| `t-metal-1.png` | REJECT | shredded RDF with a rusted steel pipe and aluminium foil |
| `t-clean-1.png` | ACCEPT | clean dry shredded feedstock (paper, cardboard, plastic film, textile) |
| `t-ambiguous-1.png` | ESCALATE | damp mixed waste with wet organic residue clumps |

Use these to demo the gate on a realistic truck-bed framing.
